B3FT04P0Évolution : Câble de frein de stationnement
DEPUIS OPR 7669
Application depuis le numéro d’OPR : 7669.
1. Description
Le câble de frein de stationnement est plus court, et son parcours est modifié.
1.1. Ancienne disposition
Figure : b3bp13nd
Le câble de frein de stationnement ( 1) passe entre la caisse (2) et la traverse (3).
1.2. Nouvelle disposition
Figure : b3bp13pd
Le câble de frein de stationnement ( 5) passe sous la traverse (4).
Le câble de frein de stationnement ( 5) est fixé sur une patte (6) par un collier plastique (8).
2. Réparation
NOTA : Seules les nouvelles pièces sont disponibles au service des Pièces de Rechange.
Opérations à effectuer :
  • Poser le câble de frein de stationnement ( 5)
  • Poser le collier (8) (serrer modérément)
ATTENTION : Le câble de frein de stationnement ( 5) doit pouvoir coulisser dans le collier (8) lors des débattements du bras de suspension.
IMPERATIF : Respecter un espace de 10 mm entre le câble de frein (5) et le tube de frein (7) (si nécessaire, déformer le tube avec précaution).
