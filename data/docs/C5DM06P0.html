1.2. Identification d’une étiquette : C15
Figure : c5dp02dc
C1 = CITROEN.
C = CLAUSOR.
F = Date de fabrication.
R = La première lettre ne sert pas dans le code clé de contact (antivol).
NP = Ces 2 lettres servent au code clé.
5 = Type de la tête de la clé de contact.
SSR = Ces 3 lettres servent au code clé.
1.3. Identification d’une étiquette : AX
Figure : c5dp02ec
C1 = CITROEN.
C = CLAUSOR.
F = Date de fabrication.
P = La première lettre ne sert pas dans le code clé de contact.
SNR = Ces 3 lettres servent au code clé.
5 = Type de la tête de la clé de contact.
PP = Ces 2 lettres servent au code clé.
1.4. Montage des paillettes sur un barillet
Figure : c5dp02fc
À l’aide d’une pince à becs fins, engager les ressorts ( 1) puis engager les paillettes une à une dans leur logement respectif, en fonction du code de la clé de contact.
NOTA : Chaque paillette doit être engagée dans son logement par la face ( 2), l’ergot (3) orienté du côté du ressort (1).
Vérifier le fonctionnement du barillet en engageant la clé de contact dans son logement . Aucune paillette ne doit dépasser du cylindre de barillet.
NOTA : Il est possible de retrouver le code clé en relevant les cotes (pied à coulisse ou réglet) " X" sur la clé de contact ou la cote "A" sur les paillettes (voir tableau ci-dessous).

2.2. Opérations à effectuer
Figure : c5dp02hc
Placer l’outil [A] dans un étau.
Positionner le verrou sur l’outil [ A].
Introduire la clé [ D] dans le verrou.
Figure : c5dp02jc
Positionner la cassette vide en orientant son bord le plus large vers l’intérieur de l’outil [ A] (suivant flèche ).
Serrer la vis " a" pour immobiliser la cassette.
Figure : c5dp02kc
Mettre les ressorts en place à l’aide de l’outil [ E].
Figure : c5dp02lc
Comprimer les ressorts à l’aide de l’outil [ A1] en orientant l’empreinte du peigne vers l’extérieur de l’outil [A].
Figure : c5dp02mc
Maintenir le peigne [ A1] en pression sur la cassette.
Prendre le peigne [ A2] et le faire coulisser sur l’outil [A] en engageant ses aiguilles dans les trous inférieurs de la cassette.
NOTA : L’empreinte du peigne [ A2] est visible.
Figure : c5dp02nc
Dégager le peigne [ A1] de la cassette.
Figure : c5dp02pc
Prendre la clé de contact du véhicule avec sa plaquette d’identification.
Relever le numéro d’identification de la clé sur la plaquette.
Sélectionner les pistons correspondant au numéro à composer en prenant soin de neutraliser le chiffre quelle que soit sa position.
La composition du numéro s’effectue à partir des lettres restantes (pour mémoire, les lettres retenues doivent correspondre aux repères des pistons du coffret).
Figure : c5dp02qc
La longueur des pistons de barillet composants le coffret est variable en fonction de la lettre qui leur est attribuée.
IMPERATIF : Prendre soin de ne pas mélanger les pistons de barillet . Les pistons supérieurs de barillet "Y" sont plats. Les pistons inférieurs de barillet "X" sont bombés à une extrémité.

Figure : c5dp02tc

Positionner la cassette sur le barillet.
Figure : c5dp02uc

Faire descendre l’ensemble de la cassette dans le puits du verrou à l’aide d’un marteau.
Figure : c5dp02vc
Terminer la mise en place de la cassette dans le barillet à l’aide de l’outil [ B2] et d’un marteau.
Vérifier l’engagement et l’affleurage de la cassette sur le barillet.
Figure : c5dp02wc
